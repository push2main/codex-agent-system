# 90-Day Roadmap

## Phase 1: Foundation

- finalize product definition and threat model
- define telemetry schema and incident model
- choose the initial repo bootstrap path
- set up cloud baseline and auth strategy

## Phase 2: First Protective Slice

- implement the first social-message, fake-profile, and fake-account-warning intake path
- build normalization and incident aggregation
- ship the first playbooks for social-message risk, media authenticity, phishing, and account recovery

## Phase 3: Guided Response

- add approval flows and notifications
- add parent and child-safe explanations for incidents
- add learning center v1 with incident-linked modules
- define recovery checklists and outcome tracking

## Phase 4: Beta Readiness

- add observability and test coverage
- run a hardening pass on auth, secrets, and update channels
- prepare a closed beta for a small number of households

## Milestone Check

By the end of the first 90 days, Superheld should be able to detect a narrow set of family-relevant incidents, explain them clearly, recommend learning content, and guide a household through safe response without needing a full SOC-style backend.
