## Current Default Direction

- Positioning: personal security platform for households, not a generic antivirus clone
- MVP: family and child safety first, especially around social media, fake profiles, deepfakes, scams, and guided learning
- Response model: deterministic rules and playbooks first, LLM support only for explanation and bounded assistance
- Safety model: human approval for high-risk actions
